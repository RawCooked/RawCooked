# 💫 About Me
AI Engineer specializing in intelligent systems, agentic workflows, and LLM-powered applications. I build end-to-end AI solutions with LangChain/LangGraph and PyTorch — from RAG architectures and multimodal AI to computer vision pipelines and production deployment.

- 🔭 Currently building **HestIA**, an AI-powered housing simulation platform (Best Advanced AI Project, BDP 2026 🏆)
- 💼 Freelance AI Engineer & Full Stack Developer, delivering LLM-powered solutions for 5+ clients
- 🎓 B.S. in Computer Science (AI specialization) @ ESPRIT School of Engineering
- 📜 5x NVIDIA Deep Learning Institute certified (Transformers, Diffusion Models, AI Agents, LLM Knowledge Injection)
- 🌐 Fluent in English, French, and Arabic

# 🚀 Featured Projects

**[HestIA](https://github.com/RawCooked) — AI-Powered Housing Simulation Platform** `2026`
PropTech platform with 3D room reconstruction, neighborhood intelligence, and an agentic mold detection & remediation pipeline (YOLOv8 → ResNet-50 → LangGraph). 🏆 Best Advanced AI Project (BDP 2026), 2nd Place Entrepren'up Hackathon.
`PyTorch` `YOLOv8` `ResNet-50` `LangGraph` `LangChain` `Ollama` `ChromaDB`

**Voice AI Medical Assistant** — Speech-to-Speech Virtual GP `2025`
Multi-step reasoning pipeline (RAG + web search + document analysis) with Llama 3 (70B), Whisper STT, and LLaVA for prescription/lab report understanding. 94% speech recognition accuracy, tested on 500+ interactions.
`PyTorch` `Transformers` `Whisper` `LangChain` `RAG` `FastAPI`

**[Children's Math Intelligence Evaluation App](https://github.com/RawCooked/GoS_AI_Project)** `2025`
Multimodal pipeline (OCR + image classification + LLM reasoning) evaluating handwritten math exercises from Tunisian Ministry of Education workbooks at scale, using Qwen2-VL and Llama 3.
`PyTorch` `HuggingFace` `Qwen2-VL` `Llama 3`

**Clinical Predictive ML Dashboard (MIMIC-III)** `2025`
ETL on 50,000+ ICU records, regression model predicting ICU length of stay at 97% accuracy, deployed via an interactive Power BI dashboard on Django.
`Scikit-learn` `SQL Server` `Django` `Power BI`

**Lavande — Agentic AI Terminal Companion** `2026`
Provider-agnostic agentic CLI with streaming output, persistent memory, and 8 desktop automation tools; pluggable LLM provider and memory backend architecture.
`TypeScript` `Node.js` `Gemini API` `Zod`

**Smart Physiotherapy Center with AI & IoT** `2024`
C++ Qt application with IoT patient monitoring and GPT API integration. Selected to represent ESPRIT at Bal des Projets.
`C++` `Qt` `MySQL` `GPT API` `IoT`
